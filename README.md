# MUHSINA RAZIQ — AI CREATOR PORTFOLIO

A bold, playful, artistic, and personality-driven portfolio for **Muhsina Raziq**, AI Content Creator & Visual Storyteller.

Built as an **AI creator's digital playground**, transitioning away from dark agency templates into a vibrant visual identity led by warm coral tones, interactive character tracking, and tactile editorial aesthetics.

## ✨ Signature Interactions

1. **Avatar Stage & Parallax Tracking:**
   * Muhsina's real photoshoot portrait cleanly cut out and staged in a 3D perspective environment.
   * Multi-plane cursor tracking: background circle (2px), floating badges (12–18px), character 3D tilt & gaze tracking (8–10px) with dynamic light sheen.
   * Floating stickers: `AI VIDEO`, `PROMPT ENGINEERING`, `VISUAL STORYTELLING`, `CREATIVE AI`, `AI COMMERCIALS`.

2. **Custom Magnetic Cursor:**
   * Center dot with smooth outer ring.
   * Expands into `VIEW` over portfolio cards and `OPEN ↗` over CTAs.
   * Shrinks over floating navigation.
   * Gracefully disabled on touch devices.

3. **Signature AI Glowing Cursor Trail:**
   * Hardware-accelerated canvas trail with soft luminous coral and lavender particles drifting with low opacity.

4. **Floating Capsule Navigation:**
   * Top-centered glass pill capsule with backdrop blur and subtle border.
   * Section-aware theme switching: automatically adapts to dark capsule mode on light sections (About, Toolkit) to maintain high contrast.

5. **Services Cursor Preview Window:**
   * Hovering over any service (`01 AI Content Creation` to `06 AI Consulting`) smoothly pulls up a floating preview card with video/image previews that follows the cursor.

6. **Interactive Cinema Lightbox:**
   * Bento gallery with instant hover video playback and category filters (`Commercials`, `Cinematic`, `Product Ads`, `Storytelling`, `Experiments`).
   * Fullscreen modal featuring HD video streaming with 206 partial content support, concept breakdown, tools used, and a one-click **"Copy Prompt"** button.

7. **Creative 3D Toolkit:**
   * Floating chips for ChatGPT, Gemini, Claude, Kling AI, Flow, CapCut, etc., with 3D tilt and role popovers.

8. **Minimal Underlined Contact Form:**
   * Editorial input lines with instant validation and simulated transmission feedback.

## 🚀 Running Locally

The project includes a built-in Node.js server with HTTP range request support for smooth MP4 video playback.

```bash
# Start the local server
node server.js
```

Open your browser at:
```
http://localhost:3000/
```
